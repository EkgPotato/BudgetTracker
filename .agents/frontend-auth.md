# Zadanie: frontend i połączenie API

Cel: zastąpić mocki prawdziwym klientem API oraz dodać widoki logowania i rejestracji w Vue.

- Zachowaj identyfikację Grosik i istniejący layout po zalogowaniu.
- Token JWT przechowuj lokalnie i dołączaj w nagłówku Authorization.
- Obsłuż pierwszą rejestrację oraz komunikaty błędów.
- Po zalogowaniu pobieraj rzeczywiste dane API; nie pozostawiaj danych demonstracyjnych.
- Uruchom `npm run build` i zapisz wynik w odpowiedzi.
