# Zadanie: backend uwierzytelniania

Cel: zweryfikować i domknąć ASP.NET Core Identity oraz JWT w `Finance.Api`.

- Rejestracja pierwszego użytkownika jest publiczna; następni wymagają administratora.
- Logowanie zwraca token i dane użytkownika.
- Zasoby finansowe oraz import wymagają autoryzacji.
- Nie zmieniaj kontraktów funkcjonalnych bez potrzeby.
- Uruchom build i zapisz wynik w odpowiedzi.
